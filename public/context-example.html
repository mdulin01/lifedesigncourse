HTML vs. Markdown

Markdown is simpler and better for low-friction editing. This HTML version is better when you want a polished, interactive builder that generates a clean summary. For an AI agent, the clearest content wins — the format is just the container. Use Copy Summary to paste into a chat, or Download .md to save a reusable file.
